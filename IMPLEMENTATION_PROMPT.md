# Prompt for Claude Opus / Codex

You are a senior creative developer, art director and frontend engineer. Redesign my existing personal portfolio in-place using the attached DESIGN.md as the implementation contract. The creative direction is BELOW THE SURFACE × THE INVENTOR'S LAB × editorial design. This must feel bespoke, human and premium, not like a generic AI-generated developer template.

Read DESIGN.md completely before changing code. Inspect the repository and its instructions, existing content, assets, routes, framework, dependencies and integrations. Preserve verified content, features, SEO, URLs and backend contracts. Do not replace the project with a disconnected demo, fabricate achievements or screenshots, or upgrade the stack unnecessarily. Use actual assets and content; gracefully omit missing material and record gaps. The design is a metaphorical expedition, not a diving business website.

Execute the redesign in this session, not just a plan. Start with a short audit, then implement P0 before optional enhancements. Prioritize a distinctive hero, original contour motif, contrasting editorial compositions, strong typography, credible case studies, and fast recruiter view. Use native scrolling, progressive enhancement, responsive layouts and reduced-motion support. Use the existing stack; prefer lightweight CSS/SVG, and only add motion dependencies when justified. Avoid generic bento cards, neon gradients, glassmorphism, skill meters and unnecessary 3D.

After implementation run the actual available build/lint/typecheck/tests. Use browser screenshots and inspect desktop/mobile visual results if tools allow. Iterate on layout defects rather than merely claiming quality. Check the acceptance checklist and rubric in DESIGN.md. Report exact commands and outcomes, changed files, screenshots, unresolved content/asset gaps and performance limitations. If a tool is unavailable, say which check remains unverified. Do not push or deploy without my permission. Preserve my existing uncommitted changes.

If design details conflict with actual repository constraints, prioritize preserving functionality and accessibility, implement the closest coherent alternative and document the deviation. Do not ask me to resolve routine creative decisions; make them using the brief. Ask only when irreversible actions or unavailable essential credentials prevent safe progress.
